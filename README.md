# AtomJS — Brauzerdagi Kod Laboratoriyasi (1-ga-1 nusxa)

[https://www.atomjs.uz/](https://www.atomjs.uz/) saytining to'liq 1-ga-1 (100% bir xil) lokal versiyasi.

## Imkoniyatlar:
- **Darsliklar:** JavaScript, HTML va CSS bo'yicha bosqichma-bosqich qo'llanmalar
- **202 ta dasturlash masalalari:** Algoritmik va amaliy topshiriqlar, avtomatik test tekshiruvi bilan
- **Jonli Kod Muharriri (Monaco Editor):** Brauzerda real-vaqtda JS, HTML va CSS kodlarini yozish va natijani ko'rish
- **AtomType:** Tez yozish poygasi va natijalar statistikasi
- **Interaktiv o'yinlar:** Viktorinalar (Quiz), UNO, Blook, Word, Ovoz berish
- **Lug'at:** Dasturlash atamalari va JavaScript metodlari lug'ati
- **Mavzular:** Tungi va kunduzgi rejim (Dark / Light mode)

## Ishga tushirish:

### 1-usul (Juda oson):
`start-server.bat` faylini ikki marta bosing. Server ishga tushib, brauzeringizda avtomatik `http://localhost:3000` ochiladi.

### 2-usul (Terminal orqali):
```bash
npm start
# yoki
node server.js
```

So'ngra brauzeringizda [http://localhost:3000](http://localhost:3000) manziliga kiring.
